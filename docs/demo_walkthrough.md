# Address demo walkthrough

Start the local application with `python3 start.py` and open
http://127.0.0.1:8765.

| Step | Action | What to inspect |
|---|---|---|
| 1 | Enter 436 Avenue Joffre and 1934 | The resolved road candidate and its dated names. |
| 2 | Open Identity and Events | Source-linked names and timeline records, including broader historical context. |
| 3 | Open Atlas | The archival scan, contemporary location, and spatial uncertainty. |
| 4 | Open Sources and a Source Passport | Evidence identifiers, provenance fields, and original source URIs. |
| 5 | Download the evidence JSON | The exported dossier retains the displayed claim-to-evidence links. |
| 6 | Search Nanjing Road department store | Multiple candidates require confirmation. |
| 7 | Search 9999 Mars Road | An unsupported input remains unresolved. |

The era is a contextual hint. The timeline is not universally filtered to that
year, and the historical scan does not establish an exact house-number location.
External map images, basemap tiles, and original source pages need internet access.
The bundled evidence flow needs no model or library API key.
