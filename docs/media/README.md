# ContextLens figures and recordings

## Teaser

[contextlens-teaser.svg](contextlens-teaser.svg) is an editable, self-contained
vector schematic of the main address demonstration. A matching
[Chinese SVG](contextlens-teaser.zh-CN.svg) provides the same workflow and evidence
boundaries in Simplified Chinese. The [English PNG](contextlens-teaser.png) and
[Chinese PNG](contextlens-teaser.zh-CN.png) are exported from their SVGs at twice
their display resolution.

The three panels cover address input and alias resolution; the four dossier views;
and source inspection and export. The figure follows
[the address pipeline](../../app/place_investigation.py),
[the interface](../../frontend/src/main.ts), and
[the architecture](../architecture.md). The evidence-boundary strip describes the
current scope of the implementation.

To reproduce the raster export and check SVG content, text fit, and README links:

```bash
python3 -m pip install -r requirements-dev.txt
python3 -m playwright install --with-deps chromium
python3 scripts/render_readme.py
```

Run these commands from the repository root. On a fresh checkout, the committed
recordings satisfy the image-link checks; after changing the capture script, regenerate
the recordings before checking links. Chromium uses the installed sans-serif
fonts; the CI image includes Noto CJK for the Chinese wordmark and language badge.
The README asset workflow regenerates the PNG when its source changes.

## Walkthroughs

The numbered GIFs and static PNGs are actual browser states, generated by
[the capture script](../../scripts/capture_walkthrough.py). English recordings use
the original filenames; Chinese recordings append `.zh-CN` to the basename.
Each recording uses the corresponding app language and annotation language.
Their frame durations explain the interaction sequence. The READMEs record the
observed map-loading limitation.

After building the frontend and installing Chromium, select the recording language:

```bash
python3 scripts/prepare_vercel.py
python3 scripts/capture_walkthrough.py --language en
python3 scripts/capture_walkthrough.py --language zh
```

The README asset workflow records Chinese views from the bundled frontend, validates
both teasers, and publishes the generated images. The reproduction workflow records
English views while exercising the frontend build and application checks.

## Badges

The five badge SVGs are stored in [badges](badges). They use local assets and relative
README links so they travel with repository copies. They identify the supported
Python version, code license, interface languages, and deployment and reproduction
guides. They do not report deployment status, test results, or a security certification.
